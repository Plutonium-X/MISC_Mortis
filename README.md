# Mortis Mini mod
# Marchands de potions permettant de se métamorphoser en monstre.

Ce module ajoute 2 marchands qui vendent des potions permettant de se transformer en monstres.

Le premier marchand est dans le donjon d'Irenicus, dans la toutes petite salle derrière la cellule de Jaheira, celle avec un portail. Il vend des potions permettant de se transformer en monstres "vivants".

Le deuxième marchand est dans le temple d'Amaunator envahi par les ombres. Il vend des potions permettant de se transformer en morts-vivants.

**Notes :**
- Les marchands ont des stocks de potions infinis, les potions coûtent 1 pièce d'or et sont à usage illimité.
- Les potions ne sont utilisables que par les humains.
- Les potions ne sont utilisables que par les archétypes de base : guerrier, clerc, mage, voleur. Les paladins, rôdeurs, bardes, druides et moines ne peuvent pas les utiliser.
- Les transformations sont permanentes. Rien ne peut vous faire retourner à l'état d'humain, même pas le Ctrl+R. Alors sauvegardez avant d'essayer.
- Certains potions valent vraiment le coup (ex : Ogre pour les guerriers), d'autres sont décevantes (Tyrannoeil = Gauth qui mord (pas de rayon))
- Certains races se voient interdire certains emplacements d'objets. Lisez bien les descriptions. (ex : le minotaures ne peut plus porter armures, bottes et casques)

# Mortis Mini Mod
# Monster Transformation Potion Merchants

This mod adds two merchants who sell potions that allow you to transform into monsters.

The first merchant can be found in Irenicus' Dungeon, in the tiny room behind Jaheira's cell, the one containing a portal. He sells potions that allow you to transform into "living" monsters.

The second merchant can be found in the Temple of Amaunator, overrun by shadows. He sells potions that allow you to transform into undead creatures.

**Notes:**
- The merchants have unlimited stocks of potions. The potions cost 1 gold piece each and can be used an unlimited number of times.
- The potions can only be used by humans.
- The potions can only be used by the four base classes: Fighter, Cleric, Mage and Thief. Paladins, Rangers, Bards, Druids and Monks cannot use them.
- The transformations are permanent. Nothing can turn you back into a human, not even Ctrl+R. So save your game before trying them.
- Some potions are really worth using (e.g. Ogre for Fighters), while others are disappointing (Beholder = a biting Gauth with no eye rays).
- Some creature forms prevent you from using certain equipment slots. Read the descriptions carefully. (For example, Minotaurs can no longer wear armor, boots or helmets.)
